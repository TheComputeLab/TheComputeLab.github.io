## How to Use Documentation During Interview Preparation
When you need deeper understanding:
```text
Interview question
↓
Identify the Python concept
↓
Read the official reference
↓
Build a small example
↓
Explain the behavior in your own words
↓
Review trade-offs
```
## Interview Tip
Use official documentation to verify exact behavior when discussing implementation details. For CPython-specific topics, distinguish the language specification from behavior specific to the CPython implementation.
